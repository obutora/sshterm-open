01 · Before / After

タブを回るか、積み木を見るか。

ターミナルのタブを回る SSH Term Desktop
どれが待っているか タブを順に開いて確かめる。 一覧は「手が要る → 作業中 → 終わった」の順。積み木なら柱の頭の赤・黄で、待たせている長さまで見える。
席を外したとき 戻ってタブを開くまで分からない。 承認待ち・入力待ち・ターンの完了を OS の通知で知らせる。ウィンドウを閉じても、メニューバーで見張りを続ける。
リモートのホスト ホストごとに SSH のタブを開いて回る。 ~/.ssh/config のホストをそのまま読み、ホストごとにまとめて 1 つの一覧に。手元のマシンもホストの 1 つとして並ぶ。
上限 使った割合は、別の画面へ見に行く。 Claude Code・Codex の 5 時間と週の枠の使った割合を、左の面の左下に。60% から黄、80% から赤。
作業の場所（worktree） worktree とブランチを手で作り、そこで agent を起こす。 ホストの右クリックから、Issue / PR か名前でタスク（worktree とブランチ）を作って agent を始める。消すときは未コミットの変更などを確かめてから。

02 · 約束

agent と作業の「しがち」に、先回りします。

  1. 約束 01

    agent は、こちらが見ていないときに限って承認を待ちがち。

    だから承認待ち・入力待ち・ターンの完了を、OS の通知で知らせます。ウィンドウを閉じてもメニューバーで見張りを続け、返事はチャット表示の返事の欄からできます。

  2. 約束 02

    作業は、上限の枠に気づいたときには残りが少なくなりがち。

    だからClaude Code・Codex の 5 時間と週の枠の使った割合を、左の面の左下に出しておきます。60% から黄、80% から赤になります。

  3. 約束 03

    リモートのホストへのつなぎ方は、もう ~/.ssh/config に書いてありがち。

    だからそのまま読みます。Include・ProxyJump・IdentityFile なども。パスワードとパスフレーズは OS の保管庫（Mac はキーチェーン）に入れます。手元のマシンは SSH を通さずに、ホストの 1 つとして並びます。

  4. 約束 04

    agent を並べるほど、worktree は増えて残りがち。

    だからホストの右クリックから、GitHub の Issue / PR か自分でつけた名前でタスク（worktree とブランチ）を作り、agent を始めます。終わったら「worktree を消す」。消す前に確かめます。

  5. 約束 05

    道具の支払いは、毎月の請求で積み上がりがち。

    だから¥1,500 の買い切りです。1 本のキーで、買った本人の Mac と Windows を何台でも。キーもメールアドレスもどこにも送らず、購入から 14 日以内なら返金します。

05 · よくある質問

よくある質問

14 日の試用が終わったら、ホストの作業は止まりますか？

止まりません。14 日を過ぎるとライセンスキーを入れるまでアプリは使えませんが、ホストで動いている agent と保持シェルはそのまま動き続けます。

どの agent の状態が分かりますか？

状態の一覧とチャット表示が分かるのは、Claude Code・Codex・Oh My Pi・Pi・Copilot CLI です（スマホ版と同じ 5 つ）。ほかの CLI も、端末ではそのまま動きます。

スマホ版の SSH Term を買っています。キーは要りますか？

要ります。スマホ版（iPhone・iPad・Android）の購入とデスクトップ版はつながっていません。

Windows 11（x64）は、近日 Microsoft Store から無料で入れられるようになります。Mac で買ったライセンスキーは、Windows 版にもそのまま使えます。
