セッションを移す作業はありません。どちらも、ホストで動いている同じ agent を見ています。

  1. 外出先で

    スマホから claude に頼む

    いつもどおり SSH Term でホストに入って、指示を出します。日本語の長い指示もそのまま打てます。

  2. 移動中

    アプリを閉じても、agent は止まらない

    agent はスマホではなくホストで動いています。承認や入力を待つと通知が届き、スマホのホームにも「承認待ち」が出ます。

  3. 席に戻ったら

    Mac の一覧に、同じ agent が並んでいる

    ホストをまとめた一覧に、手が要るものから順に並びます。チャット表示で承認して、端末はペインに割って並べて、続きを進めます。

逆も同じです。Mac で走らせたまま席を立てば、続きはスマホから。

同じセッションに入れるのは、agent がホストで動いているから。

agent と保持シェルは、スマホでも Mac でもなく、ホストの stagent（SSH Term が入れる小さな補助プログラム）の中で動いています。デスクトップ版は、スマホ版が入れた stagent にそのままつなぎます。

  • スマホと Mac で同時に開いても大丈夫です。どちらから返事を送っても、同じ agent に届きます。
  • 通り道は SSH だけ。間にクラウドは挟みません。
  • スマホから入っていたその Mac にデスクトップ版を入れたなら、SSH なしで「手元のマシン」として同じ agent が並びます。

よくある質問

スマホと Mac で、同じ agent を同時に開いても大丈夫？

大丈夫です。agent と保持シェルはホストで動いていて、スマホ版とデスクトップ版はそれぞれそこにつないでいるだけです。どちらから返事を送っても、同じ agent に届きます。

スマホ版を使っていなくても使える？

使えます。デスクトップ版だけでもホストにつなぎ、初めてつなぐときに stagent を入れます。手元のマシンの agent も SSH なしで並びます。

14 日が過ぎたら、動いている agent は止まる？

止まりません。止まるのはデスクトップ版のアプリだけで、ホストの agent と保持シェルは動き続けます。スマホ版からはそのまま見られます。

Windows ではいつ使える？

近日、Microsoft Store から入れられるようになります。今買ったライセンスキーも、そのまま使えます。

ライセンスキーをなくしたら？

送り直しのページから、買ったときのメールアドレスに送り直せます。
