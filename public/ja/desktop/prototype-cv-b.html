よくある質問

スマホと Mac で、同じ agent を同時に開いても大丈夫？

大丈夫です。どちらもホストで動いている agent につないでいるだけなので、どちらから返事を送っても同じ agent に届きます。

スマホ版を使っていなくても使える？

使えます。初めてつなぐときに、デスクトップ版がホストに stagent を入れます。

ライセンスキーをなくしたら？

送り直しのページから、買ったときのメールアドレスに送り直せます。
