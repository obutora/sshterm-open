FLOW · 試用の進め方

この順に触れば、14 日で全部見られます。

ふだんの作業の横で動かすだけです。毎日触らなくても、試用は最初に起動した日から 14 日で数えます。

  1. Day 05 分

    DMG を開いて、起動する

    することダウンロードした DMG を開き、アプリを入れて起動します。ログイン時に起動するようにしておくと、明日から開き忘れません。

    見えるもの手元のマシンは SSH を通さずにホストの 1 つとして扱うので、手元で動いている agent がそのまま左の一覧に並びます。並びは「手が要る → 作業中 → 終わった」です。

  2. Day 1ホストをつなぐ

    リモートのホストをつなぐ

    すること~/.ssh/config のホストがそのまま並んでいるので、つなぎたいホストを選びます。Include・ProxyJump・IdentityFile も書いたとおりに読みます。

    見えるものホストで動く小さな補助プログラム stagent は、初めてつなぐときにアプリが入れます（スマホ版と同じもの）。パスワードとパスフレーズは Mac のキーチェーンにしまいます。Orca を使っていたなら「Orca から取り込む」で、ホストと開いていた端末を一度だけ写せます。

  3. Day 2席を外す

    ウィンドウを閉じて、席を外す

    することagent に仕事を渡したら、ウィンドウを閉じて別のことをします。アプリはメニューバーに残って見張りを続けます。

    見えるもの承認待ち・入力待ち・ターンの完了で OS の通知が来ます。開くとチャット表示で会話を吹き出しで読め、agent が聞いている選択肢はボタンで選び、下の欄から返事や承認をします。

席を外していても、待たせている agent はもう見落としません。
確かめるのに、カードは要りません。

  1. Day 4見方を変える

    左の面を積み木に切り替える

    することagent が増えてきたら、左の面を等角の積み木にします。ホストが板、agent が柱です。一覧に戻せば「ステータス別｜ホスト別」も切り替えられます。

    見えるもの墨 1 個が動いている 10 分。柱の頭の赤・黄は、こちらが待たせている長さです。柱を重ねるとグループになります。

  2. Day 5端末に入る

    必要なときだけ端末に入る

    すること手元の端末と SSH の端末を、右や下へ好きな数のペインに割って並べます。見出しをドラッグすれば入れ替えたり、移して割ったりできます。

    見えるもの保持シェルは、アプリを閉じてもホストで動き続けます。開き直せば、そのまま続きに入れます。一覧に出ない CLI も、端末ではそのまま動きます。

  3. Day 71 件まわす

    Issue からタスクを作る

    することホストを右クリックして、GitHub の Issue / PR を選ぶか自分で名前をつけると、worktree とブランチを作って agent を始めます。

    見えるもの終わったら「worktree を消す」。未コミットの変更・push していないコミット・動いているセッションを確かめてから消します。

  4. Day 10ペース配分

    上限の枠を見ながら回す

    することagent をいくつも回していると、枠が先に尽きます。左の面の左下を見て、どこに振るか決めます。

    見えるものClaude Code・Codex の 5 時間と週の枠の、使った割合。60% から黄、80% から赤になります。

  5. Day 14決める

    続けるなら ¥1,500 で買い切る

    すること手放せなくなっていたら、ライセンスキーを買って入れます。サブスクはありません。要らなければ、何もしなくてかまいません。請求は来ません。

    15 日目キーを入れるまでアプリは使えません。それでも、ホストで動いている agent と保持シェルは止まりません。途中の仕事を落とさずに、ゆっくり決められます。
