プライバシーポリシー

SSH Term は、あなたのデータを運営者のサーバーに送りません。アカウントの登録もありません。デスクトップ版を買うときだけ、ライセンスキーを作って届けるために、下に書くものが運営者の Worker を通ります。Worker は何も保存しません。

アクセス解析・広告・追跡・クラッシュレポートの SDK は入れていません。接続先の情報、パスワード、SSH 鍵は端末の中に暗号化して置きます。

制定日：2026年11月5日 · 改定日：2026年11月13日

運営者と対象

このポリシーは、iruyo software（以下「運営者」）が提供する次のものに適用します。

  • iOS と Android のアプリ SSH Term（スマホ版。iOS での表示名は SSH Term X、com.obuto.sshterm）
  • Mac と Windows のアプリ SSH Term Desktop（デスクトップ版）
  • アプリがあなたのホストに入れるエージェント stagent
  • デスクトップ版のライセンスキーを作って届ける Worker（sshterm.iru-yo.com の下）
  • このサイト（sshterm.iru-yo.com）

スマホ版：端末に置くデータ

スマホ版が扱うデータは、端末の中に置きます。運営者には届きません。

データ置き方
接続プロファイル（ホスト名・ポート・ユーザー名・パスワード）、SSH 鍵、コマンドの履歴、通知の設定（ntfy のトピックとトークン、チャットの通知先の URL）AES で暗号化して置きます。暗号化の鍵は Keychain（iOS）・Keystore（Android）に置きます。
アプリの設定、カスタムテーマ、ファイラのブックマーク、確かめたホスト鍵、アプリロックの PIN端末の中に置きます。PIN はハッシュにして置き、PIN そのものは残しません。
  • Android では、端末のバックアップ（Google のバックアップ）にアプリのデータが含まれることがあります。暗号化したデータの鍵は含まれないので、別の端末に戻しても読めません。
  • 設定のバックアップ（JSON）と秘密鍵のバックアップは、あなたが操作したときだけ、あなたが選んだ場所に書き出します。設定のバックアップは暗号化しませんが、接続プロファイル・SSH 鍵・パスワード・PIN・ntfy のトークン・チャットの URL は入れません。秘密鍵のバックアップは、あなたが決めたパスフレーズで暗号化します。

スマホ版の通信先

スマホ版が通信するのは次の先だけです。

  • あなたが指定した SSH サーバー：入力した文字、ファイル、コマンドは、端末からそのサーバーに直接送ります。
  • Google Fonts（fonts.gstatic.com）：Google Fonts の書体を初めて使うときに、書体のファイルを取得します。このとき Google には IP アドレスなどの通信の情報が届き、Google のプライバシーポリシーに従って扱われます。
  • App Store・Google Play：応援（アプリ内課金）の商品の表示と購入、レビューの画面を開くときに使います。
  • GitHub（github.com/obutora/stagent のリリース）：stagent を入れるときに、まずホストが取得します。ホストから取得できないときだけ、端末が取得して SFTP でホストに送ります。

テーマギャラリー、お問い合わせのフォーム、ガイドなどのリンクは、あなたがタップしたときに外部のブラウザで開くだけです。

通知（stagent）

プッシュ通知やチャットへの通知は、端末ではなく、あなたのホストで動く stagent が送ります。送り先は、あなたが設定したものだけです：ntfy（既定のサーバーは ntfy.sh）、Slack、Discord、Telegram、汎用の webhook。

  • 通知に入るのは、ホストの名前（接続プロファイルの名前）、タスク名、エージェント名、作業ディレクトリの名前、定期実行の名前、決まった文言（「承認待ち」など）と、承認待ちのときのツール名（例：Bash）です。端末の出力は入れません。
  • 通知のリンクに入るホストとセッションの ID は、https://sshterm.iru-yo.com/open#… の # の後ろに入るので、このサイトのサーバーには届きません。
  • 通知の中身は、各サービスを通り、その履歴に残ります。扱いは各サービスの規約とプライバシーポリシーに従います。
  • stagent は運営者のサーバーに何も送りません。更新の確認やテレメトリもありません。

デスクトップ版

デスクトップ版が扱うデータは、手元のマシンの中に置きます。運営者には届きません。

  • 接続先は ~/.ssh/config から読むだけで、書き換えません。~/.ssh の known_hosts も読むだけで、新しく信じたホストの鍵はアプリの中に置きます。パスワードは OS の保管庫に置きます。SSH 鍵はアプリの中に持たず、~/.ssh と ssh-agent のものを使います。
  • 通信するのは、あなたが指定した SSH サーバー、stagent を入れるときの GitHub（github.com/obutora/stagent のリリース）、Mac で更新を確かめて取得するときの GitHub（github.com/obutora/sshterm-desktop のリリース）だけです。Windows の更新は Microsoft Store が行います。手元のマシンの stagent は、ネットワークを通さずに起こします。
  • OS の通知は、アプリが手元のマシンで出します。stagent の通知の送り先（ntfy など）には何も書きません。
  • 試用の期間は、アプリの中だけで数えます。ライセンスキーはアプリに埋め込んだ公開鍵で確かめるので、購入のあと、アプリがキーのために外へ通信することはありません。キーにメールアドレスは入りません。
  • クラッシュレポートの SDK は入れていません。

このサイト

このサイトは Cloudflare Pages で配信しています。Cookie、アクセス解析、広告は使いません。ページは、サイト自身のファイルのほかに何も読み込みません。

通知のリンク（/open）とテーマのリンク（/theme）の中身は、URL の # の後ろに入るので、サーバーには届きません。配信のために、Cloudflare が IP アドレスなどの通信の記録を扱うことがあります。

スマホ版の購入

スマホ版の購入と応援（消耗型のアプリ内課金）は、App Store または Google Play で行います。支払いの情報は Apple・Google が扱い、運営者は受け取りません。購入の状態は端末の中でだけ確かめます。

デスクトップ版の購入

デスクトップ版の購入では、次の先にデータが渡ります。運営者は、どれも自分のサーバーに保存しません。

渡る先渡るもの使い道
Stripe と Link（販売者）決済の画面で入れたもの（メールアドレス、支払いの情報、国など）決済、領収書、税、返金。Link のプライバシーポリシーと Stripe のプライバシーポリシーに従って扱われます。
運営者の Worker（Cloudflare Workers）購入が終わったページから、Checkout Session の id。Stripe から、その購入のメールアドレスと支払いの状態。送り直しのページでは、あなたが入れたメールアドレスと、あなたの IP アドレス。支払い済みかを Stripe に確かめ、ライセンスキーを作って返し、メールで送るため。送り直しのページでは、IP アドレスは 1 つのアドレスから 10 分に送れる回数を絞るためだけに使い、その数はメモリにだけ置いて、時間が過ぎれば消えます。データベースを持たず、何も保存しません。
Cloudflare Email Service送り先のメールアドレスと、メールの本文（ライセンスキー）license@sshterm.iru-yo.com からキーのメールを送るため。Cloudflare のプライバシーポリシーに従って扱われます。
Cloudflare Turnstile（送り直しのページだけ）人とボットを見分けるために Turnstile が読む、ブラウザーと端末の情報と、あなたの IP アドレスボットに送り直しのページを使わせないため。Cloudflare の Turnstile のプライバシーの補足に従って扱われます。
  • カードなどの支払いの情報は、運営者には届きません。
  • 購入の記録（メールアドレス、国、金額など）は Stripe に残ります。運営者は、問い合わせと返金に応えるために、Stripe の管理画面でそれを見ることがあります。
  • Worker とメールは Cloudflare の上で動くので、Cloudflare が IP アドレスなどの通信の記録を扱うことがあります。

スマホ版の端末の権限

  • ネットワーク・ローカルネットワーク：SSH サーバーに接続するため。
  • フォアグラウンドサービスと通知（Android）：アプリを切り替えている間も SSH の接続を保ち、その状態を通知に出すため。
  • 写真（iOS）：あなたが選んだ写真やファイルを、サーバーへの送信や背景の画像に使うため。
  • Face ID・指紋：アプリのロックを解くため。生体の情報は OS が扱い、アプリは受け取りません。

カメラ、位置情報、連絡先は使いません。

スマホ版のクラッシュの情報

クラッシュレポートの SDK は入れていません。エラーの画面は、報告の文をクリップボードにコピーするだけで、どこにも送りません。運営者が見るのは、あなたが端末の設定で Apple・Google への共有を許したときに各社が集計するレポートだけです。

保持と削除

  • スマホ版を削除すると、端末の中の SSH Term のデータはすべて消えます。書き出したバックアップは、あなたが消してください。
  • stagent とその設定は、あなたのホストにあります。ホストから消せます。
  • ntfy・Slack・Discord・Telegram に届いた通知は、各サービスで消してください。
  • 運営者の Worker は何も保存しません。デスクトップ版の購入の記録は、Link と Stripe のポリシーに従って Stripe に残ります。キーのメールは、あなたのメールボックスから消してください。
  • お問い合わせのフォーム（Google フォーム）に書いた内容は、返信と対応のためだけに使います。
