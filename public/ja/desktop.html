よくある質問

導入前によくいただく疑問をまとめました。そのほかのご相談はお問い合わせからお気軽にご連絡ください。

スマホ版を使っていなくても使えますか？

はい、デスクトップ版だけでそのまま使えます。手元のマシンの agent は SSH なしで自動表示され、リモートホストへも初めてつなぐときに必要な補助プログラム（stagent）を自動で入れます。

14 日間の試用が終わったら、勝手に課金されますか？

いいえ、絶対に自動課金されません。試用にクレジットカード登録もアカウント作成も不要です。14 日が過ぎるとライセンスキーを入れるまでアプリが止まりますが、ホスト側で動いている agent と保持シェルは止まりません。

Claude Code 以外の AI や、普通のターミナルとしても使えますか？

はい。Claude Code や Codex などの coding agent に加え、手元と SSH の通常ターミナルや、アプリを閉じても動き続ける保持シェルとしても使えます。ペイン分割や内蔵ファイラもそのまま利用できます。

仕事用の Mac と自宅の Mac など、複数台で使えますか？

はい。1 本のライセンスキーで、購入したご本人の Mac と Windows PC なら何台でも使えます。

スマホ版と Mac で、同じ agent を同時に開いても大丈夫ですか？

大丈夫です。agent と保持シェルはホスト側で動いていて、スマホ版とデスクトップ版はそれぞれそこにつないでいるだけです。どちらから返事を送っても、同じ agent に届きます。

コードや会話が外部のクラウドに送られることはありますか？

ありません。リモートホストとは SSH で直接通信し、間にクラウドサーバーは挟みません。手元のマシンは SSH すら通さずローカルで直接つながります。

Windows ではいつ使えますか？

近日、Microsoft Store から無料でインストールできるようになります。今ご購入いただいたライセンスキーも、そのまま Windows 11 で使えます。

ライセンスキーをなくしたり、返金したいときは？

キーをなくしたときは送り直しのページから購入時のメールアドレスへ再送できます。購入から 14 日以内の返金はお問い合わせからご連絡ください。
