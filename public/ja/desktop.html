見守りの拠点

  • 手元のマシンとリモートのホストで動く agent（Claude Code など）を、左の一覧にホストごとにまとめて出します。
  • 承認待ちや入力待ちの agent には、チャット表示から承認や返事をします。
  • 承認待ち・入力待ち・ターンの完了を、OS の通知で知らせます。
  • 端末は、必要になったときに入る場所です。手元の端末と SSH の端末を、ペインに好きな数だけ割って並べます。保持シェルは、アプリを閉じてもホストで動き続けます。
  • 手元のマシンは、SSH を通さずにホストの 1 つとして扱います。リモートのホストは、スマホ版と同じ stagent でつなぎます。
